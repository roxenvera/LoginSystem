# Supabase setup

This app connects to Supabase PostgreSQL using PHP's native `pgsql` extension.
Enable `pgsql` in the PHP version selected by MAMP.

## Connection settings

In Supabase, open **Project Settings > Database** and copy the connection
details. For a direct connection, use host `db.<project-ref>.supabase.co`, port
`5432`, database `postgres`, and user `postgres`. If the direct host is not
reachable from your network, use the Supavisor session pooler details instead;
the pooler username usually includes the project reference.

Set these environment variables in the Apache configuration used by MAMP (for
example, with `SetEnv` directives in `httpd.conf`), then restart MAMP's servers:

```apache
SetEnv SUPABASE_DB_HOST "db.<project-ref>.supabase.co"
SetEnv SUPABASE_DB_PORT "5432"
SetEnv SUPABASE_DB_NAME "postgres"
SetEnv SUPABASE_DB_USER "postgres"
SetEnv SUPABASE_DB_PASSWORD "your-database-password"
```

Keep the real password out of this project and do not commit it. The connection
uses `sslmode=require`.

## Required table

Run [`supabase.sql`](supabase.sql) in the Supabase SQL Editor to create the
`public.users` table expected by the login, registration, and profile pages.

The `password` column stores hashes generated by PHP's `password_hash()`; never
store plain-text passwords. This app uses the database directly and does not
need a Supabase API key.
